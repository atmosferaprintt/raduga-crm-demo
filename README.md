# Демо СРМ типографии «Радуга»

Демонстрационная версия (только интерфейс, без сервера): всё работает прямо в браузере.
Все данные вымышленные, цены условные и не являются реальным прайсом.

Внизу слева кнопка «Глазами…»: переключение между должностями без выхода, данные демо при этом сохраняются.

Вход: любой пароль. Логины:
- `demo` — генеральный директор;
- `petrov` — руководитель отдела продаж (все заказы, снимает фиксацию цены);
- `ivanova` — менеджер-технолог (только свои заказы и клиенты);
- `master` — директор по производству (весь цех, без цен);
- `pechatnik` — печатник офсетной и цифровой печати (совмещает две должности);
- `pereplet` — переплётчик и другие участки, экран «Мои задания»;
- `otk` — контролёр ОТК, экран «Приёмка ОТК»;
- `sklad` — кладовщик (только склад).

Что посмотреть:
- Настройки → «Должности и права»: шаблоны должностей по документу типографии, свои должности;
- Настройки → «Пользователи»: несколько должностей на человека, участки, отдельные права;
- Настройки → «Журнал действий»: кто менял права, цены, отметки цеха, решения ОТК;
- Производство: исполнитель задания, приёмка ОТК, журнал с исправлениями, простои по причинам;
- «Мои задания»: назначенные мне и общие задания участка, пауза с причиной, поля результата;
- техкарта в калькуляторе (книги 7БЦ и брошюры), карточка заказа (задания участкам).
