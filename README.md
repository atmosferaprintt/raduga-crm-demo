# Демо СРМ типографии «Радуга»

Демонстрационная версия (только интерфейс, без сервера): всё работает прямо в браузере.
Все данные вымышленные, цены условные и не являются реальным прайсом.

Внизу слева кнопка «Глазами…»: переключение между ролями без выхода, данные демо при этом сохраняются.

Вход: любой пароль. Логины:
- `demo` — руководитель;
- `master` — мастер цеха (очереди участков, отметки за сотрудников);
- `pechatnik` — печатник, экран «Мои задания»;
- `pereplet` — переплётчик.

Что посмотреть: техкарта в калькуляторе (книги 7БЦ и брошюры), Производство (очереди участков,
журнал выработки, план и факт), карточка заказа (задания участкам), Настройки → Производство.
